
# MeloDy

> Dead simple music player.

---

## About the Project

**MeloDy** is a lightweight desktop application built with **C#** and **Windows Forms**.  
Main Features:

- Select a music folder which is then saved to  musicPath.cache
- Search songs based on title, artist, or album and clear search 
- Music list is cached in an xml file for faster loading when the app starts 
- Next, Prev, Start buttons 
- Button to sync the library if the cache needs an update
- Button to change music folder path
- Interactive seekbar
- Statistics like total songs in a path and the total playtime of a list
